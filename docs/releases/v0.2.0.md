# Configurações 0.2.0

Esta versão transforma a interface inicial em um ponto central de configurações para
Cinnamon/Linux Mint, mantendo as onze categorias e o identificador técnico
`org.monolito.Settings`.

## Destaques

- card integral para o painel Temas do Mint e acompanhamento automático de modo,
  cor de destaque, tema GTK, ícones, cursor e fonte via GSettings/portal XApp;
- ícones semânticos em Dispositivos e cards inteiros acionáveis para os módulos;
- controles diretos para notificações, mouse/touchpad, acessibilidade, privacidade,
  animações e barras de rolagem;
- cobertura dos 31 módulos Python e dos três painéis do control center do Cinnamon,
  ferramentas Mint conhecidas e descoberta de extensões instaladas;
- integração com `mintlocale`/Language Support para idiomas e language packs atuais;
- contas locais sem enumerar usuários do Active Directory;
- atalho administrativo para editar `sssd.conf` no editor padrão via GVfs;
- pacote Debian com supressão reversível do launcher principal do Cinnamon.

## Pacote

Instale com:

```sh
sudo apt install ./monolito-settings_0.2.0_amd64.deb
```

Ao remover o pacote, o `.desktop` original do Cinnamon é restaurado automaticamente.

SHA-256: `99dc988e8748bbf1aafb2565d189d40d49bb2f7a9cadedde08d8a8dd34b0711b`
