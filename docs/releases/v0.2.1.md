# Settings 0.2.1

This maintenance release refreshes the user-facing documentation in English and
keeps the package and release workflow aligned with the current Cinnamon/Linux
Mint integration.

## Highlights

- concise installation and usage guidance for end users;
- automatic Mint appearance synchronisation and native-settings routing;
- reversible replacement of the primary Cinnamon Settings launcher.

Install with:

```sh
sudo apt install ./monolito-settings_0.2.1_amd64.deb
```

The release workflow writes the SHA-256 of the package it publishes here before
uploading the asset.
