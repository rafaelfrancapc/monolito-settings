# Fonte da marca

Família: Montserrat Alternates. Estilo: Bold (700).
Origem: https://github.com/google/fonts/tree/main/ofl/montserratalternates
Arquivo original: MontserratAlternates-Bold.ttf, sem alterações.
Licença: SIL Open Font License 1.1, incluída em OFL.txt.

Uso: marca textual `monolito`, sempre em minúsculas. A instalação da fonte
é feita por scripts/install.sh; a execução direta pelo Cargo segue as instruções
do README principal. Os demais textos continuam utilizando a fonte de interface
selecionada pelo usuário.
